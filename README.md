# JLU Campus Cloud Map

吉林大学校园信息可视化展示平台。
1.项目介绍
本项目是一款面向吉林大学校园信息展示的前端网站，
通过网页形式展示不同校区的校园环境、历史文化、建筑信息以及生活服务等内容。

2.技术栈
- HTML5
- CSS3
- JavaScript
- Web页面布局设计

3.主要功能
- 吉林大学多个校区信息展示
- 校园建筑图片浏览
- 校园历史文化介绍
- 校园环境展示
- 页面交互效果实现

4.项目特点
- 完成校园信息网站整体设计
- 实现多页面网站架构
- 结合图片资源进行可视化展示
- 提升用户浏览体验
